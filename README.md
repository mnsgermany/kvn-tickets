# КВН «Решающее направление» · Контроль билетов

Веб-сканер QR-билетов: 6 администраторов, одна общая база (Firebase Firestore), работает на iPhone и Android прямо в браузере.

- **Проходите**: зелёный экран и добрый звук.
- **Билет уже активирован**: жёлтый экран, сигнал ошибки, показывает, кто и когда пропустил.
- **Билета нет в базе**: красный экран и злой зуммер.
- **VIP**: один общий код, пропускает всегда, каждый проход пишется в журнал.

## 1. Firebase (один раз, ~10 минут)

1. https://console.firebase.google.com → **Добавить проект** → имя, например `kvn-tickets`. Google Analytics не нужен.
2. **Build → Authentication → Начать → Email/Password → Включить.**
3. Там же **Users → Add user**, шесть раз:
   `admin1@kvn-scan.local` … `admin6@kvn-scan.local`, у каждого свой пароль. На входе в приложение логин просто `admin1`.
4. **Authentication → Settings → User actions → снять галку «Enable create (sign-up)».** Так никто чужой не зарегистрируется.
5. **Build → Firestore Database → Create database** → регион `eur3` → режим **production**.
6. **Firestore → Rules** → вставить содержимое `firestore.rules` → **Publish**.
7. **Настройки проекта (шестерёнка) → Общие → Ваши приложения → `</>` Web** → зарегистрировать и скопировать из `firebaseConfig` значения `apiKey`, `authDomain`, `projectId`, `appId` в `config.js`.
8. **Authentication → Settings → Authorized domains → Add domain** → `<твой-логин>.github.io`.

## 2. GitHub Pages

Залить папку в репозиторий → **Settings → Pages → Deploy from a branch → main / root**. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`. После каждого push сайт обновляется сам.

## 3. Первый запуск

Войти как `admin1` → **Билеты** → «Выпустить билет» ×5 и «Создать VIP». У каждого билета есть кнопка QR: скачать PNG или «Поделиться».

## Камера

- **iPhone**: только Safari или Chrome, во встроенном браузере Telegram камера не работает. Чтобы разрешение не спрашивалось каждый раз: «аА» в адресной строке → Настройки веб-сайта → Камера → **Разрешить**. **Беззвучный режим на iPhone глушит звуки** — переключатель сбоку должен быть выключен.
- **Android (Chrome)**: разрешение спрашивается один раз. Если нажали «Запретить»: значок слева от адреса → Разрешения → Камера.
